# Session 03 - REACT

This session for training about ReactJS for front-end development with TypeScript

## 1 - Tech Stack

React: [https://react.dev](https://react.dev)

## 2 - Vite
 
Vite is the build tolls for the web

Vite: [https://vite.dev](https://vite.dev)

**Install Vite**

* use ***npm***

```shell
$ npm create vite@latest
```
* use ***yarn***

```shell
# install yarn
$ npm install --global yarn

# install vite with yarn
$ yarn create vite
```

## 3 - Create React application with Vite and TypeScript

* use ***npm***

```shell
$ npm create vite@latest <project-name> -- --template react-ts
```

* use ***yarn***

```shell
$ yarn create vite <project-name> -- --template react-ts
```

## 4 - Run React application

### 4.1 Install node-module

* use ***npm***

```shell
$ npm install
```

* use ***yarn***

```shell
$ yarn install
```

### 4.2 Build and run React application

* use ***npm***

```shell
$ npm run dev
```

* use ***yarn***

```shell
$ yarn run dev
```
